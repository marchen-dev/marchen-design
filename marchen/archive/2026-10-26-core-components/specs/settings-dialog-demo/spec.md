## 目的

用核心组件拼出一个完整的设置弹窗，检验组件组合成整页后仍然符合设计规格，并作为截图回归的整页场景。

### 需求: 结构

设置弹窗 demo MUST 由左侧导航和右侧内容区组成。左侧导航列出至少三个设置分类，选中项用灰色圆角底表示，MUST NOT 使用强调色、加粗或左侧竖条。右侧内容区 MUST 按分组展示设置项：分组标题在卡片外、字号小、颜色为次要文字；分组内每一行左侧为名称（可带一行说明），右侧为控件。

#### 场景: 切换分类

- **GIVEN** 设置弹窗处于打开状态
- **WHEN** 点击左侧导航中的另一个分类
- **THEN** 该分类变为选中（灰色底），右侧内容切换为该分类的设置项

### 需求: 只使用核心组件

demo MUST 只使用 marchen-design 的核心组件和语义 token 组合而成，MUST NOT 引入其他组件库，MUST 通过设计规则检查。

#### 场景: 设计规则检查

- **WHEN** 对 demo 源码运行设计规则检查
- **THEN** 没有违规

### 需求: 覆盖常见控件

demo MUST 至少包含：开关、选择器、单行输入框、复选框、按钮（主操作和次要操作各一个）、带说明的设置行，以及一个危险操作（如退出登录、清除数据）。

#### 场景: 控件齐全

- **WHEN** 浏览 demo 的所有分类
- **THEN** 能找到上述每一种控件

### 需求: 强调色克制

在默认分类下，一屏中使用强调色的元素 SHOULD 不超过 5 处，主操作按钮 MUST 使用黑白反色。

#### 场景: 强调色数量

- **WHEN** 打开 demo 的默认分类
- **THEN** 使用强调色的元素不超过 5 处
- **AND** 主操作按钮为黑白反色

### 需求: 在预览站和截图回归中可用

demo MUST 出现在预览站的 demos 区，MUST 能以「明暗 × 强调色」的单格地址独立渲染，并纳入截图回归。

#### 场景: 截图回归包含 demo

- **WHEN** 运行截图回归
- **THEN** 包含设置弹窗在浅色、深色以及两种强调色下的截图
