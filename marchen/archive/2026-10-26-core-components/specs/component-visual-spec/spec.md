## 目的

规定 marchen-design 所有组件共同遵守的视觉规格，让每个组件单独看、拼成整页看都属于同一个系统。

### 需求: 圆角由单一 token 派生

所有组件的圆角 MUST 由 `--radius` 按固定比例派生（控件 0.8 倍、容器 1 倍、弹窗 1.4 倍、内层项 0.6 倍），MUST NOT 写死像素值或使用与 `--radius` 无关的圆角。`--radius` 的默认值 MUST 为 0.5rem（8px）。

#### 场景: 修改 token 后全部组件按比例变化

- **GIVEN** 一个安装了 base 的项目
- **WHEN** 把 `--radius` 从 0.5rem 改为 0.25rem
- **THEN** 按钮、输入框、卡片、弹窗、弹层的圆角都按比例变小
- **AND** 不需要修改任何组件代码

### 需求: 圆角层级

组件圆角 MUST 分为四档并满足：内层项 < 控件 < 容器 < 弹窗。
- 控件：按钮（含图标按钮）、单行输入框、选择器触发器、tooltip；
- 容器：卡片、popover、下拉菜单与选择器的弹出层、toast、多行输入框、标签页列表；
- 弹窗：dialog；
- 内层项：弹出层中的选项高亮、标签页触发器、复选框。

嵌套元素的圆角 MUST NOT 大于外层元素。胶囊形（完全圆角）MUST 只用于开关和滚动条滑块。

#### 场景: 同类控件圆角相同

- **WHEN** 并排渲染按钮、输入框和选择器触发器
- **THEN** 三者的圆角半径相同，且都不是胶囊形

#### 场景: 同类容器圆角相同

- **WHEN** 分别渲染卡片、popover、toast 和多行输入框
- **THEN** 它们的圆角半径相同

#### 场景: 选项高亮与弹出层同心

- **WHEN** 打开选择器，鼠标悬停在某个选项上
- **THEN** 选项高亮的圆角小于弹出层的圆角

#### 场景: 卡片放在弹窗里

- **WHEN** 在弹窗中放置卡片
- **THEN** 卡片的圆角小于弹窗的圆角

#### 场景: 只有开关是胶囊形

- **WHEN** 检查所有组件的圆角
- **THEN** 只有开关轨道、开关滑块和滚动条滑块为胶囊形

### 需求: 控件尺寸

控件默认高度 MUST 为 32px；提供小号尺寸的控件，小号高度 MUST 为 28px。控件内正文字号 MUST 为 13～14px。组件 MUST NOT 提供高于 36px 的尺寸档位。

#### 场景: 默认高度一致

- **WHEN** 并排渲染默认尺寸的按钮、输入框、选择器触发器
- **THEN** 三者高度都是 32px

### 需求: 浅色模式的深度

浅色模式下，只有浮层（弹窗、popover、下拉菜单、选择器弹出层、tooltip、toast）MAY 带阴影；平铺的元素（卡片、输入框、标签页、按钮）MUST NOT 带阴影或只允许极轻的阴影（不超过 shadow-sm 档）。卡片与底色之间 MUST 用底色差和一像素边框区分。

#### 场景: 卡片无阴影

- **WHEN** 在浅色模式下渲染卡片
- **THEN** 卡片没有投影，通过白色底和一像素边框与页面区分

### 需求: 深色模式的深度

深色模式下，浮层 MUST 带一像素浅色边框，层级 MUST 通过"底色更亮 + 边框"表现，不得依赖阴影来区分浮层与底色。

#### 场景: 深色弹层可辨识

- **GIVEN** 深色模式
- **WHEN** 在页面上打开 popover
- **THEN** popover 的底色比页面底色更亮，并有一圈浅色细边框

### 需求: 状态颜色分工

开关开启、复选框选中、标签页选中指示（如适用）、进度、焦点环 MUST 使用强调色。悬停、按下、菜单项高亮 MUST 使用灰阶，MUST NOT 使用强调色。主操作按钮（default 变体）MUST 为黑白反色，不使用强调色。

#### 场景: 开关开启为强调色

- **GIVEN** 强调色为绿色
- **WHEN** 开关处于开启状态
- **THEN** 开关轨道为绿色

#### 场景: 菜单悬停为灰色

- **WHEN** 鼠标悬停在下拉菜单的某一项上
- **THEN** 该项底色为灰色，不是强调色

#### 场景: 焦点环为强调色

- **WHEN** 通过键盘把焦点移到输入框
- **THEN** 输入框显示强调色的焦点环

### 需求: 默认指针

所有交互元素 MUST 保持系统默认指针，MUST NOT 使用手形指针。

#### 场景: 悬停时指针不变

- **WHEN** 鼠标悬停在按钮、开关、选项、标签页触发器上
- **THEN** 指针保持系统默认箭头

### 需求: 通过设计规则检查

所有组件源码和 stories MUST 通过设计规则检查（无渐变、无调色板颜色、无写死色值、非浮层无大阴影、无手形指针、内容层无毛玻璃）。

#### 场景: 全部组件通过检查

- **WHEN** 对 registry 运行设计规则检查
- **THEN** 没有违规
