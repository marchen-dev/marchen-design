# marchen-design 设计原则

SKILL.md 的硬规则来自这里。遇到规则没覆盖的情况，按这里的原因判断。

## 颜色分工

| 角色 | 用什么 | 用在哪 |
| --- | --- | --- |
| 主操作 | Button `default`（浅色下黑底白字、深色下白底黑字） | 保存、确定、开始使用、新建 |
| 状态 / 身份 | 强调色（`primary`、`text-primary-text`、`ring`） | 开关开启、复选框选中、进度、焦点环、链接、当前用户 |
| 其余一切 | 纯中性灰阶（`background`、`card`、`muted`、`border`、`muted-foreground`） | 文字、底色、边框、悬停、选中项底色 |
| 危险 | `destructive` | 删除、退出登录、清除数据 |

- **为什么主操作不用强调色**：强调色一旦既表示"可点"又表示"状态"，就失去了辨识度。黑白主操作足够醒目，强调色留给状态，一屏只有少数几处，反而一眼能看到。
- **一屏最多一个 `brand` 按钮**。大多数页面不需要它。
- 强调色用作文字时用 `text-primary-text`，不用 `text-primary`：前者在浅色下更深、深色下更亮，保证对比度。
- 灰阶是纯中性的（不带蓝调）。不要用 `slate`、`zinc`、`gray-*` 调色板，它们大多偏蓝。

## 层级与深度

| | 浅色 | 深色 |
| --- | --- | --- |
| 层级方向 | 越往上越白（background 浅灰 → card 白） | 越往上越亮（background → card → popover 逐级变亮） |
| 浮层（弹窗、弹出层、提示、toast） | 一圈细边框 + 淡阴影 | 只有细边框，不用阴影 |
| 平铺内容（卡片、输入框、按钮） | 底色差 + 一像素边框，不用阴影 | 同左 |
| 遮罩 | `bg-overlay` | `bg-overlay`（更暗） |

- **为什么深色下不用阴影**：深色底上阴影几乎看不见，或者变成一圈脏边。层级靠"更亮的底色 + 边框"。
- 卡片放在大面积容器里时，容器要用 `bg-background`，卡片（`card`）才会比底色亮。不要把容器设成 `bg-card` 或 `bg-popover`。
- 不用毛玻璃（`backdrop-blur`）做内容层；只有遮罩允许轻微模糊（组件已内置）。

## 形状

圆角全部由 `--radius` 派生，分四档：

| 档位 | class | 用于 |
| --- | --- | --- |
| 内层项 | `rounded-sm` | 弹出层里的选项高亮、标签页触发器、复选框 |
| 控件 | `rounded-md` | 按钮、输入框、选择器触发器、导航项、tooltip |
| 容器 | `rounded-lg` | 卡片、弹出层、toast、多行输入框 |
| 弹窗 | `rounded-xl` | dialog |

- 嵌套时内层圆角不大于外层。
- 只有开关和滚动条滑块是胶囊形。不要把按钮、输入框改成 `rounded-full`。
- **为什么不能用 className 改圆角**：会破坏四档层级，同一屏出现多种圆角语言。

## 尺寸与密度

- 控件默认高 32px（`h-8`），小号 28px（`h-7`），没有更大的档位。
- 正文 `text-sm`（14px），说明文字 `text-[0.8rem]`（约 13px），分组标题 `text-xs`。
- 信息偏紧凑：工具类界面不用超大标题配大片留白。页面标题用 `text-base font-medium` 就够了。
- 字体使用系统字体栈（已在 token 中设置），不要引入 Inter、Geist 等字体包。

## 交互

- 交互元素保持系统默认指针，不加 `cursor-pointer`。
- 悬停、按下用灰阶变化，不用强调色。
- 立即生效的开关用 Switch；需要提交后才生效的用 Checkbox，并配"保存"按钮。

## 禁用清单（以及为什么）

| 禁止 | 原因 |
| --- | --- |
| 渐变（背景、文字、按钮、边框） | 最典型的"AI 生成界面"特征 |
| Tailwind 调色板颜色（`bg-blue-500`、`text-gray-500`…）和写死的色值 | 绕过 token，换强调色、切深色时不会跟着变 |
| 强调色以外的装饰性彩色（彩色图标、彩色徽章、彩色卡片背景） | 稀释强调色，画面变花 |
| 非浮层元素使用 `shadow-lg` 及以上 | 平铺内容靠底色和边框区分，阴影只属于浮层 |
| emoji 当图标 | 风格不统一；图标用 lucide 线性图标 |
| 内容层毛玻璃 | 降低可读性，也是常见的 AI 风格 |
| `cursor-pointer` | 保持桌面应用的系统指针 |
| 给每个列表项、卡片都加图标 / 徽章 / 插图 | 信息密度下降，视觉噪音 |
